## 一、专利核心原理

### 1.1 问题背景

逆变器等功率设备在高温高湿环境中运行时，壳体内环境温度因大功率模块发热而升高，但某些轻载模块（如 DC/DC 单元）自身发热量小，导致其温度低于环境温度。当模块表面温度低于露点温度时，发生**凝露**，造成电气绝缘下降、短路、开关管失效。

### 1.2 核心创新

**利用现有母线电压作为热管理执行器，实现"零硬件增量"的防凝露控制。**

```
物理链：V_bus ↑ → P_loss ∝ V^1.8 ↑ → 模块自发热 ↑ → T_mod ↑ → ΔT ↓ → 凝露风险消除
辅助链：Fan ↓ → R_th ↑ → 散热减缓 → 热量保留 ↑
```

控制判据：当任一模块的 ΔT = T_amb − T_mod > 预设阈值时，触发防凝露控制。

### 1.3 热物理模型（一阶 RC 热网络）

```
dT_mod     P_loss     (T_mod − T_amb)
------ = --------- - -----------------
  dt        C_th         C_th · R_th

其中：
  P_loss = P_loss0 × (V_bus / V_nom)^1.8  — 功率损耗与母线电压呈 1.8 次方关系
  R_th   = R_th0  × (fan_nom / fan)       — 热阻与风扇转速成反比
  C_th   = 1000 J/K                        — 模块等效热容（含散热器）
```

电-热类比：温度 ↔ 电压，热功率 ↔ 电流，热阻 ↔ 电阻，热容 ↔ 电容。

稳态温度：T_ss = T_amb + P_loss × R_th
热时间常数：τ = R_th × C_th = 0.48 × 1000 = 480 s ≈ 8 min

### 1.4 分级控制策略

```
ΔT > 7°C（高风险）→ 模式2：大幅升压 +68V/周期
5°C < ΔT ≤ 7°C（轻度风险）→ 模式1：适度升压 +40V/周期
ΔT ≤ 5°C（安全）→ 模式0：降压恢复 −24V/周期 + 降风扇保温
```

**关键发现**：在 T_mod < T_amb（风险期）降风扇会阻碍环境向模块的热传导，反而恶化凝露。仿真验证：风扇降至 15% 时暴露量反增 41%。最终策略：风险期仅升压（不降风扇），风扇仅在恢复阶段（T_mod 已接近 T_amb）适度降低保温（最低 50%）。

### 1.5 专利权利要求覆盖

| 权利要求 | 内容 | 仿真实现 |
|---------|------|---------|
| 1 | 存在 ΔT > 阈值的模块 → 增加母线电压 | ΔT > 5°C 触发升压 |
| 2 | 目标电压 = f(母线电压下限, 预设参数) | V_target ∈ [580, 880] |
| 3 | 温差-参数映射关系 | 三级 if-else 决策树 |
| 4 | 闭环调节至所有模块 ΔT ≤ 阈值 | ΔT ≤ 5°C 逐步恢复 |
| 5 | 逐级增量调节 | dV_step = 40V/周期 |
| 6,7 | 降风扇转速辅助 | 恢复阶段降风扇（最低 50%） |
| 8 | 两温差分级：第一温差升压，第二温差升压+降风扇 | 4°C/7°C 两档 |

### 2.2 Simulink 模型

模型文件 `anti_condensation_control.slx` 由 `build_simulink_model.m` 程序化构建。

**信号流**：
```
T_amb (From Workspace) ─→ [T_diff] ─→ [÷R_th] ─→ [P_net] ─→ [×1/C_th] ─→ [Integrator] ─→ T_mod
                            ↑                        ↑ -                                    │
                            T_mod                    P_loss ← [V^1.8] ← [V_Smoothing] ← [Controller]
                            │                                                       ↑
                            └────────────────── [V_Delay] ← V_bus ──────────────────┘
```

**关键模块**：
- `AntiCondensation_Controller` (MATLAB Function)：分级控制逻辑，persistent tick 计数器实现 20s 采样周期
- `Discrete Transfer Fcn`：一阶惯性平滑，α = 1-e^(−0.5/8) = 0.0606, τ=8s
- `Discrete-Time Integrator` (Forward Euler)：dT/dt → T_mod, SampleTime=0.5s
- `Unit Delay`：V 和 fan 反馈路径中打断代数环，SampleTime=0.5s, InitialCondition=620/100
- `Goto/From`：无连线信号路由（T_amb, V_bus_target, fan_target）

**StopFcn 回调**：仿真结束后自动从 `simOut` 读取数据，计算风险指标，生成 4 面板对比图并保存 PNG。

**7 个彩色功能区域标注**：
① 环境温度 T_amb（绿）② 功率损耗模型（蓝）③ 热动态模块（橙）④ 控制器（红）⑤ 电压平滑与限幅（紫）⑥ 风扇限幅（青）⑦ 输出监控（灰）

### 2.3 控制器代码

```matlab
function [V_tgt, fan_cmd] = fcn(T_mod, T_amb, V_cur, fan_cur)
    persistent tick
    persistent V_target
    if isempty(tick)
        tick = 0;
        V_target = 620.0;
    end
    deltaT = T_amb - T_mod;
    fan_cmd = fan_cur;
    if tick == 0                    % 每 40 步(20s)执行一次
        if deltaT > 5.0            % 存在凝露风险
            if deltaT > 7.0        % 高风险
                V_target = min(V_cur + 68.0, 880);
            elseif deltaT > 4.0    % 轻度风险
                V_target = min(V_cur + 40, 880);
            end
        else                       % 无风险，逐步恢复
            if V_cur > 625.0
                V_target = max(620.0, V_cur - 24.0);
            end
            if V_cur > 700.0
                fan_cmd = max(fan_cur - 6.0, 50);   % 恢复阶段降风扇保温
            end
            if fan_cur < 97.0 && V_cur <= 630.0
                fan_cmd = min(100.0, fan_cur + 5.0); % 恢复正常
            end
        end
    end
    tick = tick + 1;
    if tick >= 40, tick = 0; end   % 40 × 0.5s = 20s 采样周期
    V_tgt = V_target;
end
```

## 五、关键设计决策与讨论

### 5.1 T_amb 作为独立外部输入

T_amb 是预设的指数+正弦+噪声函数，不受控制系统反馈影响。这一简化的前提是：被控模块发热量（12~23W）远小于壳体内其他大功率模块的发热量，对壳体环境温度的贡献可忽略。如果场景是小型壳体或仅有少数模块，则需要加入壳体热方程形成双向热耦合。

### 5.2 一阶 RC 热网络的适用性

一阶模型适用于防凝露这种慢动态（分钟级）、集总参数场景，关注的是模块壳温而非结温峰值。若用于 IGBT 结温保护或寿命评估，需要 3~4 阶 Foster/Cauer 网络来捕捉芯片层（τ~10ms）到散热器（τ~100s）的多时间常数响应。

### 5.3 风扇降速的双面性

| 场景 | 降风扇效果 | 原因 |
|------|:----------:|------|
| T_mod < T_amb（凝露风险期）| 恶化风险 | 减少环境→模块热传导 |
| T_mod ≈ T_amb（恢复阶段）| 辅助保温 | 保留模块热量 |
| T_mod > T_amb（模块已升温）| 帮助保温 | 减少模块→环境散热 |

### 5.4 仿真与专利的差异

| 层面 | 专利 | 仿真 |
|------|------|------|
| 多模块场景 | 描述"各功率模块"差异化控制 | 仅单模块 A/B 对比 |
| 风扇降速时机 | 风险期升压+降风扇同时 | 风险期仅升压，恢复期降风扇 |
| 物理模型 | 定性描述"电压升→产热增" | P ∝ V^1.8 定量建模 |
| ΔT 映射 | "正相关"定性 | dV_step/1.7× 定量标定 |

### 5.5 多模块仿真的局限性

当前仿真仅模拟一个模块在不同控制策略下的表现（A/B 对比），未实现专利中描述的多模块共享母线场景。多模块的真实挑战在于：V_bus 公共调节 → 满载模块被过度加热 → 需依靠独立风扇全速散热抵消。实现多模块仿真需扩展为：各模块独立热参数（P_loss0,i, C_th,i, R_th0,i），共享 T_amb 和 V_bus，控制器取 max(ΔT_i) 决策 V_bus，风扇各自独立调节。

### 5.6 Simulink 实现要点

- **0.5s 步长**：在所有离散模块（Discrete-Time Integrator、Unit Delay、Discrete Transfer Fcn）上显式设置 SampleTime = '0.5'
- **离散求解器**：MATLAB Function 块的 persistent 变量要求 FixedStepDiscrete 求解器
- **代数环打破**：Unit Delay 在 V/fan 反馈路径提供 z⁻¹ 延迟，使 V_cur(k) = V_bus(k−1)
- **采样周期**：控制器内 tick 计数器，40 步 × 0.5s = 20s
- **StopFcn**：通过 `ReturnWorkspaceOutputsName = 'simOut'` 将数据输出到 base workspace，StopFcn 中 `evalin('base', 'simOut')` 读取并生成对比图

## 七、创新点总结

1. **零硬件增量**：利用现有母线电压调节能力实现热管理，无需加热器/除湿机/三防漆
2. **分级温差阈值**：三级决策替代简单 ON/OFF，类似 PID 比例带思想，兼顾效果与能耗
3. **逐级增量调节**：阶梯式爬坡避免电压突变对电网的冲击
4. **产热+保温双机制**：升压增加自发热 + 降风扇减少散热，但须在正确阶段（恢复期）降风扇
5. **温差-参数映射**：ΔT 与目标电压呈正相关，实现前馈+反馈复合控制
6. **逐模块差异化监测**：每个模块独立温度采集和风扇控制，以"最冷模块"为基准
7. **独立风扇作为差异化自由度**：共享母线约束下，风扇是唯一可独立调节的差异化手段
